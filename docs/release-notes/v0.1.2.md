# TVCanvas for Home Assistant 0.1.2

Documentation only: no change to the integration itself.

- A simpler setup diagram in the README: the TVCanvas app shows a code, you type it into
  Home Assistant, and you're done. Home Assistant is connected and your phone is paired for
  photos.
- The setup and privacy pages describe the code more simply.

Updating is optional. In HACS or Settings → Marketplace, open TVCanvas, select **Update**,
then restart Home Assistant.
