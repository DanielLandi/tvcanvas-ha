# TVCanvas for Home Assistant 0.1.1

A small fix release for Samsung The Frame.

## Fixed

- **My Photos no longer fills up silently.** When a pin reaches Home Assistant with
  *Replace previous* off, every image stays on the Frame, as before, but Home Assistant now
  logs a warning once per pin (`Replace previous is off for this pin`) and keeps a record of
  the images it uploaded, so they can be cleaned up later.
- **Deletes that fail are retried.** If the Frame refuses to delete the previous image, or
  the connection drops mid-delete, Home Assistant logs it once and tries again on the next
  update instead of leaving the image behind.

## New

- **A cleanup script for a Frame full of copies.** Test builds of the TVCanvas app before
  November 2026 sent group pins with *Replace previous* off, so a fast group filled My
  Photos. `scripts/frame_cleanup.py` removes only the images Home Assistant can prove it
  uploaded, never your own art, and is a dry run unless you add `--apply`. See
  [My Photos filled with copies?](https://github.com/DanielLandi/tvcanvas-ha/blob/main/docs/troubleshooting.md#samsung-frame).
- The README now opens with what [TVCanvas](https://tvcanvas.app) is.

## Upgrade

In HACS or Settings → Marketplace, open TVCanvas, select **Update**, then restart Home
Assistant. Nothing to reconfigure; your pins and paired phones stay.
